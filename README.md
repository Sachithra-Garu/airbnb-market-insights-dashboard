# Airbnb Market Insights Dashboard

An interactive Tableau dashboard that analyses Airbnb listing data to uncover insights on pricing, availability, location performance, and listing characteristics.

## Live Dashboard

[View the interactive dashboard on Tableau Public](https://public.tableau.com/app/profile/sachithra.garusinge/viz/AirBnBFullProject_17952784541790/Dashboard1?publish=yes)

## Business Objective

To support data-driven decisions by identifying patterns in Airbnb pricing, availability, and location-based performance.

## Tools and Skills

- Tableau
- Data cleaning and preparation
- Calculated fields
- Interactive filters and parameters
- Data visualisation
- Dashboard design
- Analytical storytelling

## Dashboard Features

- Interactive filters for exploring key dimensions
- Pricing and availability analysis
- Location and listing-type comparisons
- KPI visuals and trend analysis
- Executive-ready dashboard layout
